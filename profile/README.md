## Get started in seconds

```bash
# Run with Docker
docker run -p 9090:9090 ghcr.io/relatadb/relatadb:latest

# Pick your SDK
pip install relata-sdk                        # Python
npm install @zysec-ai/relata-sdk              # TypeScript
go get github.com/relatadb/sdk-go             # Go
```
